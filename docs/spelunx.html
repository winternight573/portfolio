spelunx — CAVERN Toolkit

A Unity SDK that lets novice and seasoned developers build for CAVERN, a multiplayer roomscale VR platform — shipped with tutorial, sample scenes, and open documentation.

Role Technical Designer, Developer Evangelist
Team CMU ETC Spring 2025 Team Spelunx
Tools Unity 6, GitHub, Perforce
Links Project site · GitHub · Docs

01 Overview

Strealining onboarding and empowering development for a novel platform through click-to-add Unity editor tools, comprehensive documentation, and a sample scene that demonstrates best practices for the platform's unique interaction design space.

Team Spelunx created a Unity SDK that automates stereoscopic rendering, Vive Tracker (position tracking), Orbbec Femto Bolt (body tracking) integration, and spatial audio setup. Beyond the click-to-add editor tools, we also designed a sample scene showcasing best practices for the platform's unique interaction design space, and comprehensive documentation both to use the toolkit and to extend it. The toolkit is designed for both novice and seasoned developers.

As the technical designer and developer evangelist on the team, I:

  • Conducted user research with the platform's current and prospective developers to uncover pain points and needs for feature prioritization
  • Collaborated with the toolkit developers and art team to implement the sample scenes
  • Led the tutorial and documentation strategy and creation
  • Validated the toolkit effectiveness through 2 game jam playtests, and 20+ user tour sessions with developers of varying backgrounds and experience levels
  • Communicated the toolkit design rationale to the broader development community through weekly devlogs on the project's website.
